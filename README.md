# Real-Time Character Counter

## Project Description
This project is a simple Real-Time Character Counter developed using HTML, CSS, and JavaScript. It allows users to enter a message in a text area and displays the number of characters typed and the remaining characters allowed.

The maximum character limit is set to 200 characters.

## Features
- Simple and user-friendly message input area.
- Maximum character limit of 200 characters.
- Real-time character counting while typing.
- Displays the total number of characters entered.
- Displays the remaining characters allowed.
- Prevents users from typing beyond the maximum character limit.
- Displays a warning message when the character limit is reached.

## Technologies Used
- **HTML5** – To create the message input area.
- **CSS3** – To style the text area and character counter.
- **JavaScript** – To implement real-time character counting and validation.

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in your web browser.
4. Type a message in the text area.
5. Observe the character counter updating automatically.

## Character Limit
The maximum allowed characters are **200**.

Example:
- Characters entered: 150
- Remaining characters: 50

When the user reaches 200 characters, a warning message is displayed.
